# ISLAND 启动片头与主题皮肤设计

**状态：** 文档审阅通过，待用户确认
**目标版本：** 后续补丁版本
**适用环境：** DeepSeek Harness Windows 桌面版 0.2.0-rc.2；其他版本需单独验证

## 目标

在现有 `dsh-island-theme` 插件中加入一个原创的应用内启动片头和可切换的 ISLAND 配色皮肤。视觉以用户博客的暖白、苔绿、青柠、浅网格和克制轨道动效为基础。默认皮肤为「岛屿原野」。片头采用用户认可的简洁轨道构图，只加入淡刻度与柔和扫描光。

## 方案选择

1. **插件管理页中的插件设置（选定）：** 在 `dsh-island-theme` 的配置页选择皮肤，使用 Harness Host 持久化用户设置。主工作区不增加常驻控件，选择立即应用。
2. **工作区常驻皮肤按钮：** 在侧栏或工具栏增加弹出面板，并在客户端本地存储选择。入口更快，但会占用原生界面空间，且状态较难与其他窗口同步。
3. **只提供固定皮肤：** 用户通过启用不同包或改配置切换。实现简单，但不满足在插件内切换皮肤的目标。

采用第一种方案。Harness 的插件管理页提供 bundle 专属配置扩展点，设置服务负责 Host 配置读写；实现时需按 0.2.0-rc.2 的实际接口进行适配和验证。[插件配置页](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-plugin-manager/README.md) · [设置服务](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-settings/README.md)

## 用户体验

### 启动片头

- Harness 工作台每次启动时播放一次，目标时长约 1.4 秒。
- 片头覆盖应用内容区域，不替换 Windows 原生窗口标题栏或系统启动画面。
- 动画顺序为浅网格与柔和光晕显现、ISLAND 标记与轨道光点出现、片头淡出并显示工作台。
- 片头提供「跳过」按钮并响应 Escape；没有用户操作时自动淡出。
- 装饰进度线只表示片头动画时间，不显示或暗示 Harness 的真实加载进度、模型状态或网络状态。
- 尊重 `prefers-reduced-motion`：启用减少动态效果时跳过动画，不旋转轨道或扫描光。
- 片头从浏览器客户端插件 effect 启动，因此显示时机是客户端模块激活时。它不是比 Harness 首帧更早的系统级启动画面；若插件未启用或模块加载失败，工作台按原样显示。

### 主题皮肤

- 在插件管理页的 `dsh-island-theme` 专属设置页选择皮肤。
- 提供「岛屿原野」（默认）、「森林夜色」和「纸笺暖棕」三套配色。
- 每套皮肤均提供浅色和深色令牌；Harness 原生浅色、深色或跟随系统选择仍决定当前色阶。
- 切换后当前窗口立即更新；Host 持久化选择，使插件重载和后续启动仍采用所选皮肤。
- 未知或无效配置安全回退到「岛屿原野」。插件关闭、卸载或设置页无法注册时，原生 Harness 仍可使用。

## 架构与数据流

- `client-runtime.mjs` 增加启动片头生命周期：在文档中创建单一 overlay，监听跳过和 Escape，并设置短时自动清理；插件 effect 卸载时移除计时器、事件与 overlay。
- 现有主题 CSS 扩展为三套 skin token。通过受控的 `data-island-skin` 属性选择令牌，不移动、替换或改写 Harness 的 React 节点。
- 插件客户端在官方 `plugins.bundle.config` 扩展点注册皮肤选择页；配置通过 Harness 设置服务读写 Host 持久化字段。
- 每个工作台窗口监听设置服务的已接受配置快照。皮肤页保存后，当前窗口和其他已连接窗口都更新 `data-island-skin`；新窗口启动时先读取最近一次已接受值，再挂载片头。
- 生成的 `client.js` 继续由 `npm run build` 从运行时代码和 CSS 生成，包仍保持一个 `dsh-island-theme` 插件。
- 默认值固定为 `island`。片头只使用本地 CSS/DOM，不请求图片、字体、接口或外部资源。

## 失败处理与无障碍

- DOM 已卸载或插件在片头期间被禁用时立即清理 overlay。
- 跳过按钮有可见焦点样式和可访问名称；Escape 只关闭片头，不拦截后续 Harness 键盘行为。
- 设置读写失败时保留上次已接受的皮肤值；初始配置不可用时先使用「岛屿原野」，之后在配置可用时更新。
- CSS 保留 Harness 的可读对比度、焦点环和减少动态效果支持；动画不会改变会话内容、权限、模型或消息状态。

## 验收标准

1. 每次新的工作台客户端启动最多显示一个片头；关闭片头后不会因 SPA 路由切换再次播放。
2. 片头在约 1.4 秒内自动退出；点击「跳过」或按 Escape 会立即退出。
3. 减少动态效果开启时不播放旋转和扫描动画，并可直接进入工作台。
4. 三套皮肤可在插件管理页选择；切换即时生效，重载后选择保留，原生浅色/深色模式继续工作。
5. 插件关闭或卸载后不残留 overlay、监听器或主题属性；设置页未加载不影响 Harness 使用。
6. 不伪报真实启动进度，不使用未授权的角色图片或外链素材，不更改 Harness 会话或功能数据。
7. 自动化 DOM 测试覆盖片头显示、自动退出、跳过、Escape、减少动态效果、单例与卸载清理，以及皮肤默认值、有效选择和无效配置回退。

## 不在范围内

- Windows 系统级启动画面、窗口标题栏或应用安装器。
- 角色立绘、第三方图片、音效、联网资源、真实进度采集。
- 修改对话、模型、权限、GitHub 自动发布或 Harness 原生主题开关。
- 在此次功能中重新设计工作区其余布局。

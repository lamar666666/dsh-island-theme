# ISLAND 启动片头与动画皮肤设计

**状态：** 用户已批准视觉方向，准备实施
**适用环境：** DeepSeek Harness Windows 桌面版 0.2.0-rc.2；其他版本需单独验证

## 目标

在现有 `dsh-island-theme` 插件中加入短时应用内启动片头、可切换的片头主视觉和动画工作台皮肤。设计使用用户博客的晨光浮岛和像素小伙伴，整体明亮、暖白、苔绿与青柠高光；不采用暗黑开场。默认工作台皮肤为「晨光浮岛」，启动主视觉默认为重新构图的浮岛，同时可切换到「岛灵」角色版。

## 方案选择

采用 Harness 插件管理页中的 `dsh-island-theme` 专属配置页，提供两个选择：工作台皮肤 (`skin`) 与片头主视觉 (`introVisual`)。设置保存在当前 Harness profile，通过 Harness 配置表单即时应用；主工作区不新增常驻切换按钮。

工作台皮肤包含「晨光浮岛」（默认、亮色）、「浮岛夜航」（仅在 Harness 深色模式下显示夜景岛图）与「岛灵同行」（晨光背景加原创像素小伙伴）。三种皮肤保留相同的聊天排版与交互区；动态效果只作用于背景光轨、选中会话标记和输入框边缘。

Harness 插件管理页提供 bundle 配置扩展点；官方文档规定可编辑 Config 字段由 Host 提供 `form.state` 和 `form.mutate(operations, expectedRevision)`，并通过 volatile Config 字段即时更新。[插件配置页扩展点](https://github.com/deepseek-ai/deepseek-harness/blob/master/packages/client/ui-plugin-manager/README.md) · [实时配置表单指南](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/cookbook/adding-a-settings-card.md)

## 用户体验

### 启动片头

- Harness 工作台每次启动播放一次，目标时长约 1.8 秒；不添加额外开关，用户可随时跳过。
- 片头覆盖应用内容区域，不替换 Windows 原生窗口标题栏或系统启动画面。
- 片头主视觉可选「浮岛」或「岛灵」。浮岛版把博客插画完整置于右侧，保留留白；岛灵版以博客原创小伙伴为亮色全息主角。
- 两个版本共用明亮入场动效：镜头轻推、青柠与薄荷青光轨显现、标题入场，随后淡出到工作台。
- 片头提供「跳过」按钮并响应 Escape；未操作时自动结束。
- 进度线只表示动画时长，不显示或暗示 Harness 的真实加载进度、模型状态或网络状态。
- 尊重 `prefers-reduced-motion`：启用减少动态效果时跳过片头与重复动画。
- 片头在浏览器客户端插件 effect 激活后开始；它不是比 Harness 首帧更早的系统启动画面。插件未启用或模块加载失败时，工作台仍按原样显示。

### 工作台皮肤

- 在插件管理页的 `dsh-island-theme` 专属配置页选择工作台皮肤和片头主视觉；片头只由插件本身的启用状态决定。
- 默认皮肤为「晨光浮岛」。浅色模式使用白昼岛图；深色模式切到夜景岛图与森林色面板。图片只作浅层背景，聊天与输入框使用磨砂表面保持文字清晰。
- 「浮岛夜航」在浅色模式用低饱和白昼岛图，在 Harness 原生深色模式使用夜景岛图和更明显的苔绿光轨；它不改变启动片头的明亮配色。
- 「岛灵同行」在浅色和深色模式都保留像素小伙伴；背景图和界面色阶跟随 Harness 原生模式，小伙伴放在工作区边角轻柔浮动，不遮挡会话内容。
- 当前窗口选择后即时更新；设置写入 profile 后，重载和后续启动沿用该选择。无效值安全回退到默认项。

## 架构与数据流

- `index.mjs` 导出 `Config` schema，为 `skin` 与 `introVisual` 提供默认值并标记为 `.volatile()`。插件管理页保存时，Host 将值写入 profile 的 `cordis.patch.yml`；`.volatile()` 让正在运行的插件即时收到更新而不需重载。
- `client.js` 使用客户端插件管理 slot 注册 bundle 配置页；页面从 owner props 接收配置快照和 `mutate`，将两个选择一起提交并持久化。工作台从 Config 的稳定引用读取当前 skin 和片头样式。
- `client-runtime.mjs` 管理单例启动 overlay、跳过按钮、Escape 监听、短时自动清理、工作台背景属性及动画皮肤运行时；插件卸载时清理事件、计时器、属性与临时节点。
- 主题 CSS 使用 `data-island-skin` 和 `data-island-intro` 选择皮肤与片头图形；使用本地博客素材，不移动或替换 Harness 的 React 节点。
- `scripts/build-client.mjs` 将压缩后的本地图像作为数据 URI 嵌入生成客户端；不请求用户机器上的博客目录、字体、视频、外部站点或 API。
- 生成的 `client.js` 保持由构建脚本生成并随插件打包。

## 失败处理与无障碍

- `skin` 和 `introVisual` 的默认值分别为 `day-island` 和 `island`；未知值回退到默认值。
- Host 配置加载失败时使用默认值；后续得到已接受值后即时应用。
- DOM 卸载或插件停用时立刻清理 overlay、监听器和计时器。
- 跳过按钮有可见焦点样式和可访问名称；Escape 只在片头活动时关闭片头。
- 皮肤保持足够对比度、焦点环和减少动态效果支持；不修改会话、模型、权限或消息数据。
- 静态素材随包提供，即使图片解码失败，也回退到纯 CSS 晨光背景。

## 验收标准

1. 每次新工作台客户端启动最多显示一个片头；路由切换不重新触发。
2. 片头约 1.8 秒内结束；点击「跳过」或按 Escape 会立即退出。
3. 插件页保存的皮肤与片头样式写入 profile，并在当前窗口立即生效；重载后值保留。
4. Harness 浅色模式使用晨光背景，深色模式使用用户选定皮肤的深色变体；「浮岛夜航」不会改变明亮片头。
5. 工作台动效在实时预览中清晰可见但不降低聊天可读性；减少动态效果启用时停止。
6. 插件卸载后不残留 overlay、监听器、计时器或 `data-island-*` 属性。
7. 不伪报真实启动进度，不使用未经用户提供或授权的角色素材，不发送网络请求。
8. 自动化 DOM 测试覆盖片头单例、自动结束、跳过、Escape、减少动态效果、卸载清理、配置更新、默认/无效值回退和皮肤属性应用。

## 不在范围内

- Windows 系统级启动画面、窗口标题栏或应用安装器。
- 音效、视频播放、真实进度采集、联网素材或分析上报。
- 修改对话、模型、权限、Harness 原生主题开关或其他工作区布局。
